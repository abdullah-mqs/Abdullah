# Abdullah Riaz — Portfolio

> **IT · Operations · Systems** — A portfolio that's more than a resume. It's a journey.

Black & white minimalism, Vercel-inspired design, and Geist font — because simplicity is the ultimate sophistication. 🖤

---

## ✨ What Makes It Special

- 🎨 **Vercel Mono Aesthetic** — Pure black + white, zero distraction
- ⚡ **Next.js 16 + Turbopack** — Lightning fast builds
- 🎭 **Framer Motion** — Smooth scroll-triggered animations
- 🧭 **Smart Scroll Spy** — Navbar underline tracks the active section automatically
- 📱 **Responsive** — Right-slide drawer on mobile, full nav on desktop
- 🎯 **Theme Variables** — Change color in one place, update the entire site
- ♿ **Accessible** — Keyboard focus rings, semantic HTML, ARIA labels

---

## 🛠️ Tech Stack

| Category        | Tech                                          |
| --------------- | --------------------------------------------- |
| Framework       | [Next.js 16](https://nextjs.org) (App Router) |
| Language        | TypeScript                                    |
| Styling         | Tailwind CSS v4 (`@theme` variables)          |
| Animations      | Framer Motion                                 |
| Icons           | React Icons (Feather + Lucide)                |
| Fonts           | Geist Sans + Geist Mono                       |
| Package Manager | pnpm                                          |

## 🚀 Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/abdullah-mqs/Abdullah.git

# 2. Install dependencies
pnpm install

# 3. Start the dev server
pnpm dev
```
